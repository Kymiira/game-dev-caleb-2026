The Mandelbrot Set

The Mandelbrot set is defined by the iterative complex quadratic polynomial formula:

Zn+1 = Zn2 + C

For each pixel on the canvas representing a complex number C, we iterate starting from Z0 = 0. If the magnitude of Z remains bounded as n goes to infinity, the point belongs to the Mandelbrot set (colored black).

If it escapes past a threshold radius, the rate of escape determines its vibrant color!
