    Inputs

    • <input type="range"> sets max tries
    • <input type="checkbox"> toggles hints

    • confirm() asks to play again

    Outputs

    • <output> with textContent shows hints and stats
    • innerHTML builds the guess history
    • <progress> shows tries left
    • alert() announces a win
    • console.log and document.title give quiet extras
    • CSS class changes color the hint box
    • createElement and appendChild build the footer list
    • A JSON file download saves the player
